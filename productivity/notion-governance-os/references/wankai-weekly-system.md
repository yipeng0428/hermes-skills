# 万凯工作台 · Hermes 运维系统

> 基于 Notion Governance OS 的 Worker 模式延伸。一套完整的个人工作管理 + AI 辅助周报系统。

## 架构概览

```
万凯工作台 (Notion Hub)
│
├── 📋 每周事务 · Weekly Log (database)  ← 日常记录
├── 📥 万凯收件箱 (database)              ← 远期想法/待办
├── 📊 周报 (auto-generated)             ← 每周六 17:30
├── 🔮 AI 洞察 (auto-generated)          ← 每周六 17:30
├── 📈 数据看板 (auto-generated)         ← 每周六 17:30
├── 🛡️ 治理面板 (from Governance OS)     ← 全Notion巡检
└── Hermes · 漫游栖所 (free roam)        ← AI 自主探索空间
```

## 周报格式（钉钉兼容）

```
【本周工作内容】     ← 按类别分组统计完成项
【本周未完成工作】   ← 进度/原因/预计完成节点
【本周工作总结】     ← 学到什么/失误/改进
【下周工作计划目标】 ← 量化+时间节点
【需协调与帮助】
【意见和反馈】
```

## AI 洞察格式

```
📊 数据总览 (完成率/P0占比/日均)
🎯 类别分布 (各类型完成率)
⚠️ 瓶颈识别 (哪些卡住了)
📈 趋势洞察 (vs上周环比)
💡 行动建议 (3-5条具体可执行)
🧠 成长观察 (技能/模板沉淀)
📥 收件箱提醒 (该启动的/该清理的)
```

## 收件箱工作流

```
有想法 → 丢进📥收件箱 → 每周六AI扫描 →
  ├── 🔥该启动 → 提醒搬入📋每周事务
  ├── 💤30天没动 → 建议清理
  └── 💡新想法 → 在洞察里提及
```

## 关键设计决策

1. **不用耗时(h)属性** — 用户觉得每日记录加耗时太繁琐，用任务数量粗略评估工作量
2. **未定稿/已定稿** — 设计类工作特有流程，区别于通用的"进行中/已完成"
3. **周报生成到Notion而非直接推钉钉** — 永久存档+可回溯，用户手动复制粘贴到钉钉只需5秒
4. **收件箱独立于每周事务** — 想法和日常任务不应混在同一视图
