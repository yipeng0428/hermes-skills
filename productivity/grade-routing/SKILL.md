# GRADE（门控路由与自适应深度）

## 触发关键词
- "门控路由" / "自适应推理" / "动态路由" / "GRADE"
- "资源分配" / "计算优化" / "高效推理" / "成本优化"

## 核心理念
不要在所有任务上用同一个模型、同一个深度。
根据任务特征动态决定：选谁做、做多深、要不要共享、要不要提前终止。

## 何时不该用

| 场景 | 原因 | 替代方案 |
|------|------|---------|
| 预算极有限（零成本） | 门控本身需要计算 | 用 `agentomics` 固定最便宜路线 |
| 低价值日常任务 | 路由优化成本>收益 | 用最便宜的模型直接做 |
| 单一确定任务 | 不需要动态路由 | 直接用最适合的模型 |
| 学习阶段 | 先理解各模型特性 | 用 `agentomics` 建立认知 |

## 快速上手（2分钟）

1. 对AI说：`门控路由：{你的任务}`
2. AI返回：任务评估等级（L1/L2/L3）+推荐模型+预计成本
3. 确认后执行

## 四层门控架构

```
门控1: Agent选择 → 根据任务类型选择最合适的Agent/模型
门控2: 层级深度 → 决定推理需要"想多深"
门控3: Agent间通信 → 决定哪些Agent需要共享信息
门控4: 分支剪枝 → 提前终止无效推理路径
```

## 执行流程

### Step 1: 任务评估
- L1（简单）：格式化、复制、分类 → 最快最便宜模型
- L2（中等）：文案撰写、简单分析 → 中等模型
- L3（复杂）：创意策略、复杂决策 → 强模型+多层思考

### Step 2: Agent路由规则
```markdown
| 任务特征 | 路由目标 |
|---------|---------|
| 需要视觉分析 | GPT-4（多模态） |
| 需要中文文案 | Claude / 文心 |
| 需要代码生成 | GPT-4 / DeepSeek |
| 需要逻辑验证 | Claude |
| 需要快速分类 | 任意免费模型 |
```

### Step 3: 动态深度控制
调用Agent → 质检输出是否足够好 → 足够则终止（节省计算）→ 不够则深化/换更强Agent

### Step 4: 分支剪枝
Agent输出明显跑题/质量差 → 立即终止该分支 → 排除该Agent

## 真实案例：万凯月报制作

```
任务：制作万凯包装月度运营报告

门控1: Agent选择
  ├─ 数据清洗+图表 → DeepSeek（性价比最高）
  ├─ 趋势分析+洞察 → Claude（逻辑分析强）
  └─ 排版+视觉设计 → GPT-4（视觉+数据结合）

门控2: 层级深度
  ├─ 数据清洗：L1（简单，直接处理）
  ├─ 趋势分析：L2（中等，需多角度思考）
  └─ 洞察建议：L3（复杂，需战略推理）

门控3: 通信控制
  └─ DeepSeek清洗的数据 → 共享给Claude分析
  └─ Claude分析结果 → 共享给GPT-4生成图表

门控4: 分支剪枝
  └─ GPT-4第一版排版 → 检查：过于花哨 → 剪枝 → 简化版

总成本：约$0.5（传统全用GPT-4约$3）
节省：83%，质量相当
```

## 注意事项
1. **门控本身要有开销效率**：门控判断要快于直接执行，否则得不偿失
2. **建立质量基线**：先跑几个任务建立"什么样算足够好"的标准
3. **避免过度剪枝**：给Agent 2-3次机会再判定失败
4. **记录决策日志**：记录每次路由决策，持续优化路由规则
