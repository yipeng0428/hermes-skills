# Flow State Engineering（心流工程）

## 触发关键词
- "心流模式" / "专注冲刺" / "flow time" / "进入状态"
- "预热启动" / "先给我思路" / "帮我破题" / "90分钟深度工作"

## 核心理念
传统"先想20分钟再动手"的心流启动方式太低效。
AI可以在2分钟内帮你"预热"大脑的模式识别网络，直接进入高效产出状态。

## 何时不该用

| 场景 | 原因 | 替代方案 |
|------|------|---------|
| 简单机械劳动 | Flow不是必须的 | 直接用批量模式碎片时间处理 |
| 多人协作会议 | 需要持续沟通 | 不适合个人Flow场景 |
| 学习新技能初期 | 基础脚手架比Flow更重要 | 用 `cognitive-externalization-loop` |
| 已极度疲劳 | Flow需要一定认知资源 | 直接休息 |

## 快速上手（1分钟）

1. 对AI说：`心流模式：{你的任务}。预热我5分钟。`
2. AI返回：3个切入角度+第一个操作步骤
3. 关手机通知，设90分钟倒计时
4. 开始执行

## 环境检查清单

开始前花30秒确认：
- [ ] 手机开勿扰模式 / 翻面放置
- [ ] 关闭微信/钉钉桌面通知
- [ ] 关闭邮件自动刷新
- [ ] 水杯已经倒好（中途不要起身）
- [ ] 洗手间已去过
- [ ] 桌面只剩当前任务相关物品

## 执行流程

### T-5分钟：AI预热（Pre-flow Priming）
```
"我需要做{任务描述}。请给我：
1. 这个任务的3种不同切入角度
2. 每种角度的关键难点和突破口
3. 我现有资源/技能最适合哪种切入
4. 直接可用的第一个操作步骤"
```

### T-0分钟：Flow-Protected Block启动
- 关掉所有通知（手机勿扰、关闭微信）
- 设置90分钟倒计时
- 将AI预热输出的"第一步"放在屏幕最显眼位置
- 准备一张纸和笔在手边（随时记走神时的杂念，然后回神继续）

### 中间60分钟：深度工作，不使用AI

**黄金规则：中间60分钟绝不用AI**
- 只做**只有你能做**的事：创意抉择、审美判断、结构决策
- **走神时**：在纸上写下杂念（不处理），然后继续工作
- **卡住时**：
  - 0-60秒：不要动，继续思考
  - 60-90秒：用AI获取"3种思路提示"（只给思路，不给答案）
  - 90秒+：用AI获取"完整方案参考"（此时继续思考已无效率）

**何时中断Flow**（极少数情况）：
- 你突然意识到方向完全错了（AI预热输出有误）
- 身体紧急需求
- 不可预测的重大中断（客户紧急电话等）

### T+15分钟：AI整理
Flow session结束后，用15分钟让AI：
1. 总结你这次session的核心产出
2. 列出遗漏和盲点
3. 下一步行动清单
4. 明天的预热输入

## 双轨时间表
| 时段 | 时长 | 做什么 | AI角色 |
|------|------|--------|--------|
| 上午Flow 1 | 90min | 高质量创意产出 | 仅预热+收尾 |
| 下午编排 | 30min | 筛选/调整/输出 | 批量辅助 |
| 上午Flow 2 | 90min | 第二轮深度产出 | 仅预热+收尾 |

## 真实案例：万凯新品详情页设计

```
09:00 → AI预热：3种切入角度
  A. 突出"抗菌PET材质"（技术参数路线）
  B. 突出"高颜值包装"（视觉冲击路线）
  C. 突出"日本技术背书"（信任背书路线）
  → 判断：B最适合当前营销目标
  → 第一步：生成3版视觉参考
09:05-10:35 → 90min纯Flow：
  09:05-09:15：收集3种视觉参考
  09:15-10:00：确定主视觉风格+构图
  10:00-10:35：完成核心设计+文案
  → 中间卡住1次（配色）→ 用AI获得3种思路 → 选冷暖对比
10:35-10:50 → AI整理：总结+遗漏检查+明天预热
```

## 效果基准
| 指标 | 无AI Flow | AI增强Flow |
|------|----------|-----------|
| 进入Flow时间 | 20-30min | 2-5min |
| 单次session产出 | 1-2hr等效 | 3-5hr等效 |
| Flow中断恢复 | 25min | 3-5min |
| 工作日Flow时段占比 | 25-30% | 45-55% |

## 注意事项
1. **AI只做脚手架，不做主体**：Flow的主体永远是你自己的深度思考
2. **不要频繁求助AI**：每次求助=一次flow中断，恢复成本25倍
3. **预热要具体**：越具体的预热输出，越快进入状态
4. **每90分钟必须休息**：不是"撑不住才休息"，而是"到点就休息"
5. **记录Flow数据**：每次记录"进入时间+产出+中断原因"，持续优化
