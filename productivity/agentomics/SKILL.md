# Agentomics（AI代理经济学）

## 触发关键词
- "代理经济学" / "资源分配" / "成本优化" / "多模型计费"
- "哪个模型最适合这步" / "成本和效果"

## 核心理念
不再问"哪个AI最好"，而是问"**这个任务步骤，用哪个AI性价比最高**"。每个AI Agent都有可衡量的生产力价值和部署成本。

## 何时不该用

| 场景 | 原因 | 替代方案 |
|------|------|---------|
| 预算极有限（零成本） | 只有免费模型可用 | 直接用 `grade-routing` 全免费模型路线 |
| 低价值日常任务 | 路由优化的成本>收益 | 用最便宜的模型直接做 |
| 创作型心流状态 | 切换模型会打断Flow | AI增强Flow |

## 快速上手（2分钟）

1. 打开角色定价表
2. 把今天的工作任务拆成3-5个子任务
3. 每个子任务问自己：这步最重要的是速度/质量/中文/创意？
4. 按定价表匹配最优模型

```
这个任务需要什么？
├─ 创意发散 → GPT-4 策划师
├─ 逻辑推理 → Claude 验证师

├─ 数据清洗 → DeepSeek 代码手
└─ 最终审核 → 你自己（不可替代）
```

## 执行流程

### Step 1: 建立AI角色定价表
见上方矩阵，根据你实际可调用的模型做调整。

### Step 2: 任务分解与路由
```markdown
任务：为万凯新品做详情页设计
1. 市场分析 → DeepSeek（性价比最高，免费额度充足）
2. 竞品对比 → Claude（逻辑分析强）
3. 创意方向 → GPT-4（创意质量最高）
4. 视觉参考 → GPT-4（需多模态理解参考图）
5. 文案撰写 → Claude（中文表达自然）
6. 质检批判 → 任意免费模型（挑毛病不需要太强能力）
7. 整体审核 → 你自己
```

### Step 3: Shapley值追踪（每周）
每周花5分钟，问自己：
- "这周哪个模型的输出被采用了最多？"
- "有没有哪个步骤用贵模型但其实便宜模型也能做？"
- "哪个步骤我应该升级模型？"

### Step 4: 成本-质量对照表（持续更新）
```markdown
| 任务类型 | 本周使用模型 | 被采用率 | 是否应调整 |
|---------|------------|---------|----------|
| 文案撰写 | Claude | 85% | 保持 |
| 创意方向 | GPT-4 | 60% | 考虑备选 |
| 数据清洗 | DeepSeek | 95% | 保持 |
```

## 真实案例：万凯包装月报制作

```
流程拆解：
① 收集月销售数据 → DeepSeek（免费，够用）
② 分析趋势+发现异常 → Claude（逻辑强）
③ 设计月报排版+图表 → GPT-4（视觉+数据结合）
④ 撰写分析文案 → Claude（中文好）
⑤ 内部评审质检 → GPT-4（模仿老板视角挑刺）

传统方式：全用GPT-4 → 月成本约$15
Agentomics优化后：DeepSeek 60% + Claude 30% + GPT-4 10% → 月成本约$4
节省：73%，质量相当
```

## 与相关技能联动
- 配合 `grade-routing` 实现自动门控路由
- 配合 `budgeted-act-defer` 设定每步的错误预算上限
- 配合 `allocation-economy` 让贵模型做创意方向，便宜模型做延展

## 注意事项
1. **不要过度优化**：Shapley精确计算的成本可能超过收益，心算即可
2. **保持2-3个备用模型**：主模型故障时可无缝切换
3. **关键步骤用最贵模型**：关键产出用GPT-4/Claude，辅助步骤用免费模型
4. **记录成本**：为每个任务段记录使用的模型和成本，便于长期优化

## 💰 Quota Monitoring & Automatic Fallback

真实测试中 Grok CLI 因API配额耗尽直接失败（`credit limit exceeded`）。多Agent编排必须监控配额。

### 配额状态表
```markdown
| Agent | API | 状态 | 备用 |
|-------|-----|------|------|
| Claude Code | Fable 5 proxy | 🟢 | — |
| Codex | OpenAI | 🔴 依赖缺失 | Claude Code |
| Grok CLI | xAI | 🔴 配额耗尽 | DeepSeek |
```

### 自动降级规则
```
派发前检查配额：
├─ 🟢 → 正常派发
├─ 🟡 → 派发+日志警告
└─ 🔴 → 自动路由到备用Agent（不打扰用户）
```

### 配额耗尽恢复
1. 检测到 `credit limit exceeded` → 标记该Agent为🔴
2. 自动切换到备用Agent继续任务
3. 报告用户："Grok配额用尽，已自动切换DeepSeek"
4. 用户可选：充值/换key/永久降级
