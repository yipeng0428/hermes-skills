# Allocation Economy（配称经济）

## 触发关键词
- "配称经济" / "批量生成" / "先出10个方案让我选"
- "多角度产出" / "批量出图" / "多版对比" / "让我挑"

## 核心理念
当AI生产成本趋近于零时，人类价值从"生产"转向"策展"。
你不再是画图的人，而是**决定画什么、选哪个、怎么组合**的人。

## 何时不该用

| 场景 | 原因 | 替代方案 |
|------|------|---------|
| 简单重复任务（改尺寸/调色） | 批量生成的成本>收益 | 直接用AI一次搞定 |
| 紧急任务（1小时交付） | 策展需要时间 | `design-agent-team` 流水线 |
| 创意枯竭期 | 你可以用3个角度突破 | `flow-state-engineering` 先破题 |
| 需要原创视觉作品 | AI出图同质化严重 | 用 `mixture-of-agents` 深度打磨 |

## 快速上手（3分钟）

1. 选一个当前任务（如"设计万凯新品Banner"）
2. 对AI说：`帮我生成10个Banner方案，每个用一句话描述核心差异，覆盖极简/国潮/科技/赛博朋克/孟菲斯/超写实/日系/复古/自然/未来10种风格`
3. 收到后，用下面的策展评分卡，30秒内给每个方案打分
4. 选得分最高的1个方向进入深度执行

**策展评分卡**（每条1-5分）：
```markdown
| 维度 | 权重 | 分数(1-5) |
|------|------|----------|
| 品牌匹配度 | x3 | _ |
| 视觉差异化 | x2 | _ |
| 执行可行性 | x2 | _ |
| 预期转化率 | x2 | _ |
| 风险可控性 | x1 | _ |
| **加权总分** | | _ |
```

## 执行流程

### Step 1: 指令设计（产出质量=prompt质量）

```
"帮我生成10个{设计需求}方案的方向/风格/排版，每个用一句话描述核心差异"
```
- 指定风格维度：极简/国潮/赛博朋克/日系/孟菲斯/超写实...
- 指定场景维度：电商Banner/详情页主图/包装展开图/社交媒体...

### Step 2: AI批量生产
用 `delegate_task` 同时启动3个子Agent，每个输出3-4个方案：
- Agent A: "从数据逻辑角度，提出3个能提升转化率的设计方向"
- Agent B: "从创意审美角度，提出3个能吸引目标用户的设计方向"  
- Agent C: "从差异化角度，提出3个能区别于竞品的设计方向"

### Step 3: 策展与选择
收到9-12个方案后，按以下标准筛选：
1. **战略匹配度**：是否贴合品牌调性和营销目标
2. **差异化**：是否区别于竞品常见做法
3. **可执行性**：在现有时间和技能范围内能否完成
4. **风险**：最坏情况是否可接受

### Step 4: 精选方向深度执行
选定1-2个方向后，让AI在这个方向上深度出图/出稿：
```
"在这个方向上，生成3个不同构图的版本" → 选择最佳构图
→ "在这个构图上，生成3个不同配色的版本" → 选择最佳配色
→ "延展到各平台尺寸"
```

## 真实案例：万凯PET瓶新包装

```
输入：帮我生成10个"万凯PET瓶新包装"设计方案
→ AI生成：① 极简水墨风 ② 赛博城市 ③ 自然植物系 ④ 几何抽象 ⑤ 日系插画风
  ⑥ 国潮复古 ⑦ 科技未来 ⑧ 孟菲斯波普 ⑨ 超写实摄影 ⑩ 渐变抽象
→ 策展评分：极简水墨(18) > 自然植物(16) > 国潮复古(15) > ...
→ 选择"极简水墨"进入深度执行 → 3种构图 → 选中轴对称 → 3种配色 → 选青绿
→ 输出：淘宝主图+详情页+拼多多主图+抖音封面+包装展开图 共5张
→ 总耗时：35分钟（传统方式约2-3小时）
```

## 效果基准
| 指标 | 传统模式 | 配称经济 |
|------|---------|---------|
| 日产出设计方案 | 3-5个 | 15-25个 |
| 创意方向多样性 | 1-2个 | 8-12个 |
| 时间/方案 | 45min+ | 8-15min |
| 决策疲劳 | 低 | 中（需训练） |

## 验证清单
- [ ] 是否生成了至少10个方案？
- [ ] 每个方案是否都有明确的差异化描述？
- [ ] 是否用了策展评分卡做选择？
- [ ] 深度执行阶段是否至少迭代了2轮？
- [ ] 最终产出是否延展到所有需要的平台尺寸？

## 与相关技能联动
- 先用 `flow-state-engineering` 破题 → 再用本技能批量产出
- 结合 `agentomics` 用不同模型生成不同方案（创意型GPT-4 + 逻辑型Claude）
- 用 `cognitive-externalization-loop` 存储"被否决的方案"作为未来参考

## 注意事项
1. **不要选择困难**：如果多个方案都OK，用"第二轮筛选"——让AI对比PK
2. **产出质量参差是正常的**：批量生产必然有好有差，这正是需要你筛选的原因
3. **建立评判标准**：提前定义"好设计"的3个维度，避免凭感觉选
4. **防止同质化**：每次加入1-2个"差异化约束"打破AI的舒适区
5. **存储"第二好"方案**：第二名的方案有时更适合下次迭代
