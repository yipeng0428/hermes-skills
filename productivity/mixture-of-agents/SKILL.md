# Mixture-of-Agents（MoA 多层混合架构）

## 触发关键词
- "MoA" / "多层精炼" / "层层提升" / "级联架构"
- "反复打磨" / "迭代优化" / "层层迭代" / "cascade"
- "先原型再打磨" / "渐进清晰"

## 核心理念
单层AI输出 → 质量有上限。
多层架构中，每层Agent以上一层所有Agent的输出为输入来精炼。
效果：仅开源模型(65.1%)超越GPT-4 Omni (57.5%)。

## 何时不该用

| 场景 | 原因 | 替代方案 |
|------|------|---------|
| 简单任务（改尺寸/调色） | 多层精炼成本>收益 | 直接用AI一次搞定 |
| 时间紧迫（1小时交付） | 多层迭代需要时间 | 用 `design-agent-team` 快速出稿 |
| 创意探索期 | 需要广度不需要深度 | 用 `allocation-economy` 批量发散 |
| 预算有限 | 多层=多倍API调用 | 用 `agentomics` 选便宜模型 |

## 快速上手（2分钟）

1. 对AI说：`MoA：{你的任务}。3层精炼。`
2. AI返回：第1层3-5个独立方案
3. 对AI说：`第2层精炼：综合以上方案，生成1个更完善的版本。`
4. AI返回：第2层精炼版
5. 对AI说：`第3层终审：整合为最终可交付版本。`
6. AI返回：最终版

## 标准3层MoA架构

```
第1层：探索层（3-5个Agent并行）
  每个Agent独立给出完整方案
  输出：5个不同方案版本
      ↓
第2层：精炼层（2-3个Agent）
  每个Agent以第1层所有输出为上下文
  输出：整合+精炼后的2-3个升级版本
      ↓
第3层：终审层（1个Agent）
  整合第2层所有输出
  输出：可直接交付的最终方案
```

## 执行流程

### Step 1: 第1层 — 多视角独立探索
同时派发3-5个Agent，每个独立输出：
- Agent 1: "从ROI和转化率角度，设计这个方案"
- Agent 2: "从视觉冲击力和差异化角度，设计这个方案"
- Agent 3: "从可落地性和成本控制角度，设计这个方案"

### Step 2: 第2层 — 交叉精炼
```
"以下是第1层5个Agent的方案：{方案1-5}
请综合所有方案的优点，生成1个更完善的方案版本"
```

### Step 3: 第3层 — 终审输出
以第2层输出为输入，生成最终可交付版本。

### ReM-MoA增强版（带记忆）
在标准MoA基础上，引入Ranked Reasoning Memory：
- 所有层的推理轨迹持久化存储
- 深层推理不会丢失浅层信息
- 特别适合5层以上的深度架构

## 真实案例：万凯Banner设计

```
第1层（3个Agent并行）：
  Agent A: "突出抗菌材质，技术参数路线" → 方案A
  Agent B: "突出高颜值，视觉冲击路线" → 方案B
  Agent C: "突出日本技术背书，信任路线" → 方案C

第2层（精炼层）：
  输入：方案A+B+C
  输出：融合版方案（抗菌+视觉+信任三要素）

第3层（终审层）：
  输入：融合版方案
  输出：可直接交付的Banner终稿（含文案+构图+配色）

总耗时：15分钟（传统方式约1-2小时）
质量：超越单Agent直接出图（细节更丰富，逻辑更自洽）
```

## 效果基准
| 架构 | AlpacaEval 2.0 | 超越GPT-4 Omni？ |
|------|----------------|-----------------|
| GPT-4 Omni（单模型） | 57.5% | — |
| MoA（仅开源模型） | 65.1% | ✅ 超越 |
| 同模型自集成 | ~55% | ❌ 不如 |
| ReM-MoA（深层） | 随深度增加优势扩大 | ✅ |

## 验证清单
- [ ] 第1层是否生成了至少3个独立方案？
- [ ] 第2层是否以第1层所有输出为上下文？
- [ ] 第3层是否生成了可直接交付的最终版本？
- [ ] 每层是否使用了不同的模型/prompt（异质性）？
- [ ] 是否检查了Co-Failure Ceiling（所有模型是否在同一问题上全错）？

## 与相关技能联动
- 配合 `consilium-protocol` 让第2层精炼变成"审议"而非简单整合
- 配合 `agentomics` 为不同层选择不同模型（探索层用便宜模型，终审层用贵模型）
- 配合 `allocation-economy` 让第1层探索变成批量生成

## 注意事项
1. **异质性是核心**：用不同模型/不同prompt，不要用同一模型复制
2. **每层必须有"信号"**：上一层输出作为辅助信息，避免重复发明
3. **3层最佳**：超过5层可能信息稀释
4. **Co-Failure Ceiling限制**：如果所有模型在同一问题上全错，任何组合都无法超越
