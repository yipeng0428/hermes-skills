# Budgeted Act-or-Defer（预算化行动-延期决策）

## 触发关键词
- "预算化决策" / "自动化分级" / "升级机制" / "act or defer"
- "什么AI做/什么人做" / "自动化边界" / "置信度阈值"

## 核心理念
AI不可能100%准确，人也不可能100%覆盖。
核心问题：**AI做到什么程度该自己做，什么程度该升级给人？**

## 何时不该用

| 场景 | 原因 | 替代方案 |
|------|------|---------|
| 低风险日常任务 | 不需要预算机制 | 直接用 `grade-routing` |
| 紧急决策 | 预算计算需要时间 | 直接升级给人类 |
| 纯创意任务 | 错误定义模糊 | 用 `consilium-protocol` 审议 |
| 已经明确知道答案 | 不需要AI判断 | 直接执行 |

## 快速上手（1分钟）

1. 对AI说：`预算化决策：{你的任务}`
2. AI返回：任务分级（P0-P3）+置信度评分+建议操作
3. 确认后执行

## 决策矩阵
|  | AI置信度高 | AI置信度低 |
|------|----------|----------|
| **影响大** | ✅ AI做 + 抽样审计 | ⚠️ 升级人类 |
| **影响小** | ✅ AI全自动 | ✅ AI做 + 标记异常 |

## 执行流程

### Step 1: 任务分级
- P0：影响极大，不可逆 → 必须人类决策
- P1：影响大，AI建议+人类确认
- P2：影响中等，AI自主+抽样审计
- P3：影响小，AI全自动

### Step 2: 置信度校准
- 置信度 ≥ 8 → 自动执行
- 置信度 5-7 → 执行 + 标记
- 置信度 < 5 → 升级人类

### Step 3: 预算监控
每月审计AI决策质量：错误率是否在预算内？超预算→下调自动化级别；远低于→可尝试上调。

## 真实案例：万凯设计任务分级

```
P0: 品牌VI重新设计（影响极大，不可逆）
  → 必须人类决策 + 外部设计师参与

P1: 新品详情页设计（影响大，转化直接相关）
  → AI生成3版方案 → 人类选1版 → AI延展

P2: 社交媒体日常图文（影响中等，可修改）
  → AI自主生成+排期发布 → 20%抽样审计

P3: 老客户简单修改（改尺寸/调色/文案错别字）
  → AI全自动处理 → 异常标记

每月审计：
  P2错误率：3%（预算5%）→ 保持
  P3错误率：1%（预算2%）→ 可尝试上调自动化范围
```

## 效果基准
| 指标 | 纯人工 | 纯AI | 预算化决策 |
|------|-------|------|----------|
| 自动化率 | 0% | 100% | 84% |
| 准确率 | 95%+ | 70-85% | 96% |
| 人工负载 | 100% | 0% | 16% |

## 注意事项
1. **预算要保守**：宁可低预算安全运行，不要贪多翻车
2. **升级≠失败**：升级给人是正常机制，不是系统出错
3. **定期校准**：AI信心和实际准确率的对齐会随时间漂移
4. **保留人工通道**：任何时候人类都可以接管AI的决定
