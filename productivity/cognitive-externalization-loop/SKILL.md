# Cognitive Externalization Loop（认知外化循环）

## 触发关键词
- "认知外化" / "外化思维" / "知识图谱"
- "帮我建立XX知识库" / "笔记自动化" / "渐进总结"
- "帮我关联" / "找到和XX相关的笔记"

## 核心理念
人脑工作记忆只有4±1个chunk。
将思考外化到Notion等结构化系统，AI持续帮你关联、总结、发现模式，
你的有效认知容量从4→40+。

## 何时不该用

| 场景 | 原因 | 替代方案 |
|------|------|---------|
| 全新的知识领域 | 没有可关联的基础内容 | 先用传统笔记法积累30条+ |
| 短期一次性项目 | 知识库建设成本>收益 | 用 `design-agent-team` 流水线 |
| 极度碎片化时间 | 来不及建立外化习惯 | 先用语音/微信记录，后整理 |
| 纯机械操作任务 | 不需要认知外化 | 直接做 |

## 快速上手（5分钟）

1. 在Notion建立一个"认知外化"数据库，包含：标题/标签/关联/AI重述/来源/状态
2. 遇到一个新想法时，立刻写入一条记录（30秒）
3. 对AI说：`帮我重述以下笔记，并找出它与已有笔记的关联：{你的想法}`
4. AI返回：重述版+5条关联建议
5. 每周日晚让AI做知识库综述

## 执行流程

### 第一阶段：外化结构设计
每条笔记包含：
- 标题（核心观点的一句话总结）
- 标签（#项目 #灵感 #决策 #学习 #客户）
- 关联笔记（双向链接到其他笔记）
- AI摘要（AI自动重述，做Feynman验证）
- 状态（草稿/已验证/已归档）
- **Feynman复选框**：AI能否正确重述=你是否真正理解

### 第二阶段：外化循环（每有新想法时）
```
新想法 → 
  ↓
写入Notion（30秒内完成）→ 
  ↓
AI自动执行：
  1. 用自己语言重述你的笔记（Feynman Technique验证理解）
  2. 找出Notion中10个关联笔记
  3. 生成"强制连接"建议："这个想法和{笔记X}有关联，因为..."
  ↓
你审查AI建议，确认或拒绝连接 →
  ↓
确认的连接存入笔记 → 知识图谱增长
```

**Feynman验证规则**：
- AI重述与你原意一致 → ✅ 真正理解
- AI重述跑偏/简化太多 → ❌ 你自己没想清楚，需要补充说明
- AI无法重述 → ❌ 说明你的表达不够清晰

### 第三阶段：内化升级（每周日）
每周让AI执行：
1. **模式检测**：本周80个笔记中，有什么重复出现的模式？
2. **孤岛笔记发现**：哪些笔记还没有任何关联？
3. **洞察建议**：基于已有笔记，建议探索的新方向
4. **知识库健康度报告**：本周新增/关联数/Feynman通过率

## 真实案例：万凯包装设计知识库

```
第1周：每天写5-8条笔记 → 累计40条
  → AI自动关联：发现"客户A偏好国潮风"与"竞品B的爆款"存在关联
  → 洞察：国潮+PET瓶可能是一个蓝海方向

第2周：累计85条 → AI发现模式
  → "日本技术背书"出现12次（最高频信任要素）
  → "抗菌材质"在客户反馈中出现但我们的设计没突出
  → 建议：把抗菌材质作为下季度核心卖点

第3个月：累计250条 → 知识图谱效应
  → 收到新品需求时，AI自动匹配历史参考（3-5个相关案例）
  → 设计决策速度提升3倍
  → 客户提案命中率提升（因为知识库能快速调用相关数据）
```

## 注意事项
1. **外化要即时**：想法出现后2分钟内记下来，否则会忘
2. **AI重述是检验**：如果AI重述跑偏了，说明你自己没想清楚
3. **不要追求完美归档**：先记录，再整理，AI会帮你后整理
4. **每周AI总结日**：固定时间让AI帮你做知识库综述
5. **"已死亡"状态笔记不要删**：它们未来可能复活
