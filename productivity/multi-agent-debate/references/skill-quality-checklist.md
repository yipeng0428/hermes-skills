# 技能品质升级检查清单

> 本清单在 2026-07-15 群智模式技能批量升级至 v1.1 时形成。
> 适用于所有自建技能的持续优化。

## 升级检查项（每项必须包含）

| # | 检查项 | 示例 | 为什么重要 |
|---|--------|------|-----------|
| 1 | **何时不该用** | 表格：场景/原因/替代方案 | 防止误用，指导降级选择 |
| 2 | **快速上手** | 1-3分钟的最低门槛操作步骤 | 降低认知负荷，提升采纳率 |
| 3 | **真实案例** | 结合万凯包装的实际场景 | 让抽象概念落地，便于模仿 |
| 4 | **验证清单** | 5个复选框（□）的验收标准 | 可操作的完成标准，而非模糊判断 |
| 5 | **相关技能联动** | 上游/下游/配套技能交叉引用 | 防止孤立使用，最大化学科技能价值 |
| 6 | **Bump 版本号** | v1.0.0 → v1.1.0 | 标记更新，方便追溯 |

## 批量升级流程

```
1. 遍历所有目标技能的 SKILL.md
2. 对每个技能逐一诊断：
   ├─ 缺少"何时不该用"？ → 添加（至少 4 个场景）
   ├─ 缺少"快速上手"？ → 添加（1-3 步操作）
   ├─ 缺少"真实案例"？ → 补充（万凯包装优先）
   ├─ 缺少"验证清单"？ → 添加（至少 5 个 □）
   ├─ 缺少"相关技能联动"？ → 添加（至少 3 个交叉引用）
   └─ 版本号 < v1.1 ？ → Bump 到 v1.1.0
3. 批量写入更新后的文件
4. 验证：skills_list 确认所有技能可见
```

## 版本号规则

- v1.0.0 — 首次创建
- v1.1.0 — 完成品质升级（6 项检查全部覆盖）
- v1.2.0+ — 内容实质性扩展（新场景/新案例/新联动）
- v2.0.0 — 架构级重构

## 常见遗漏模式

| 遗漏 | 常见于 | 修复模板 |
|------|--------|---------|
| 工具列表过长 | multi-agent-swarm, design-agent-team | 精简为 4-6 个核心工具 |
| 触发词覆盖不全 | 所有 | 搜相关领域术语同时覆盖中英文关键词 |
| 案例缺少量化数据 | budgeted-act-defer, agentomics | 必须加"效果基准"表（前后对比） |
| 没有替代方案提示 | 所有 | "何时不该用"必须指向具体替代技能 |
| 联动只列名不说明 | 所有 | 必须写"配合 X 实现 Y"的形式 |
