# v2.1 Execute Framework 新增记录

> 新增原因：2026-07-15

用户提出"本地执行类工作"场景——不是分析决策题，而是让多个Agent协作完成具体执行任务（搜索+写代码+搭自动化）。

## 核心设计

| 角色 | 职责 | 工具 |
|------|------|------|
| 采集员 | 搜索、抓取、下载 | web_search/web_extract/browser/terminal |
| 处理员 | 数据清洗、代码、分析 | read_file/execute_code/terminal/write_file |
| 交付员 | 报告、文档、cronjob | write_file/read_file/search_files |

## 关键机制

- `enabled_toolsets: ["terminal", "file", "web"]` — 执行子Agent必须获得工具权限
- 路径统一规划：`E:/hermes/output/{日期}_{任务}_*.md`
- 增量恢复：某子Agent失败只重跑那一个

## 测试记录

### 测试：AI每日新闻抓取脚本
- **任务**：写脚本每天抓取AI行业新闻摘要
- **采集员产出**：80+新闻源，5大类（国内媒体/国际媒体/研究机构/学术/社区）
- **处理员产出**：455行Python脚本，纯内置库，5个RSS源，67条新闻
- **交付员产出**：完整部署文档+cronjob配置+钉钉推送（可选）
- **验证通过**：Windows兼容、UTF-8编码、去重排序、按日期分文件

## 输出路径约定

```bash
E:/hermes/output/{任务}_{阶段}.md     # 分析报告
E:/hermes/output/{任务}/YYYY-MM-DD.md # 按日期归档
E:/hermes/scripts/{脚本名}.py         # 可执行脚本
```
