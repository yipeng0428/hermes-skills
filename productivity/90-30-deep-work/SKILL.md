# 90/30 Deep Work Protocol（超频深度工作协议）

## 触发关键词
- "超频工作" / "专注块" / "90/30" / "深度工作"
- "热身设计" / "帮我进入状态" / "今天要冲刺" / "专注时间"

## 核心理念
Deep Work在AI时代需要重新设计：
- T-15min：AI预热 → 预热大脑模式识别
- T+90min：纯深度工作 → 只做AI无法替代的部分
- T+15min：AI整理 → 总结产出+发现盲点

## 何时不该用

| 场景 | 原因 | 替代方案 |
|------|------|---------|
| 碎片化工作（随时被打断） | 无法建立90分钟block | 用 `flow-state-engineering` 短block |
| 学习新技能初期 | 需要频繁查资料 | 用 `cognitive-externalization-loop` |
| 团队协作任务 | 需要持续沟通 | 不适合个人Deep Work |
| 已极度疲劳 | Deep Work消耗认知资源 | 直接休息 |

## 快速上手（1分钟）

1. 对AI说：`超频工作：{你的任务}。T-15预热。`
2. AI返回：子问题列表+3种解决思路+第一步操作
3. 关手机，设90分钟倒计时
4. 开始执行

## 执行流程

### T-15分钟：AI预热
```
"我接下来90分钟要做{任务}。请帮我：
1. 列出这个任务的所有子问题/子任务
2. 对每个子问题，给出3种解决思路
3. 标出'只有我能做'的部分 vs 'AI可以做'的部分
4. 给出第一个可执行步骤的具体描述"
```

### T+90分钟：深度工作块
```
0-15min：AI预热输出参考 + 快速规划
15-75min：深度专注区（只做判断/审美/创意/决策）
75-90min：收尾 + 初步整理
```

**Deep-First执行原则**：
- 90分钟内只做AI无法替代的部分
- 编码/搜索/格式化/草稿 → 后置到浅层工作段
- 遇到卡住：先标注跳过，90分钟后再处理

### T+15分钟：AI整理
Deep Work结束后，用15分钟让AI：
1. 用你自己的笔记摘要 + 产出，生成结构化总结
2. 发现遗漏和盲点
3. 下一步行动清单
4. 明天的预热输入

### 双轨时间表
```
09:00-09:15  AI预热
09:15-10:45  Deep Work Block 1（高质量产出）
10:45-11:00  AI整理 + 休息
11:00-11:30  AI编排（批量筛选/输出）
14:00-14:15  AI预热
14:15-15:45  Deep Work Block 2
15:45-16:00  AI整理
16:00-16:30  AI编排（修改/延展/交付）
```

## 真实案例：万凯新品详情页设计

```
09:00 → AI预热：
  子问题：① 主视觉风格 ② 文案卖点 ③ 构图布局 ④ 配色方案
  3种思路：A. 技术参数路线 B. 视觉冲击路线 C. 信任背书路线
  第一步：收集3种视觉参考

09:15-10:45 → 90min Deep Work：
  09:15-09:30：收集参考，确定"视觉冲击路线"
  09:30-10:15：完成主视觉设计+核心文案
  10:15-10:45：延展到淘宝主图+详情页首屏
  → 中间卡住1次（配色）→ 标注跳过 → 90分钟后用AI辅助

10:45-11:00 → AI整理：
  产出：主视觉1张+文案1套+延展2张
  盲点：缺少"抗菌材质"卖点（后续补充）
  明天预热：抗菌材质视觉化方案
```

## 效果基准
| 指标 | 纯Deep Work | 90/30超频 |
|------|-----------|----------|
| 日均有效产出时间 | 5-6hr | 7-8hr |
| 高质量产出/周 | 3-4 units | 8-12 units |
| 心理疲劳度 | 高 | 中 |
| 产出质量稳定性 | 中（易卡住） | 高（AI辅助） |

## 验证清单
- [ ] T-15预热是否给出了3种可操作的解决思路？
- [ ] 90分钟内是否没有打开社交媒体？
- [ ] 是否执行了"卡住时标注跳过"策略？
- [ ] T+15整理是否发现了至少1个盲点？
- [ ] 明天是否有明确的预热输入？

## 与相关技能联动
- 配合 `flow-state-engineering` 强化Flow进入速度
- 配合 `multi-agent-swarm` 让Agent在编排段做批量延展
- 配合 `agentomics` 在预热段用便宜模型，深度段用贵模型

## 注意事项
1. **T-15预热是关键**：跳过预热直接进入=浪费前20分钟
2. **中间不用AI不是教条**：如果遇到必须查资料才能继续的任务，用AI后立即恢复专注
3. **每90分钟必须休息**：这是生理规律
4. **不要让AI编排侵占Deep Work时间**：AI编排是"辅助"，Deep Work才是"产出"
