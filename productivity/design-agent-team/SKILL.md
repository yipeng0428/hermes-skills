# Design Agent Team（设计Agent团队工作流）

## 触发关键词
- "设计团队" / "出图工作流" / "设计流水线" / "AI设计助手群"
- "帮我做详情页" / "批量出图" / "设计全流程" / "万凯设计"

## 核心理念
美工设计师 = 创意总监/CEO
AI Agent = 你的数字设计团队（策划、文案、质检、优化）

## 何时不该用

| 场景 | 原因 | 替代方案 |
|------|------|---------|
| 简单修改（改尺寸/调色） | 大材小用 | 直接用AI一次搞定 |
| 学习新技能 | 需要先理解基础 | 用 `cognitive-externalization-loop` |
| 探索全新风格 | 团队执行不适合探索 | 用 `flow-state-engineering` |
| 预算极有限 | 多Agent=多API调用 | 用 `grade-routing` 优化 |

## 快速上手（2分钟）

1. 对AI说：`设计团队：{你的任务}`
2. AI返回：任务拆解+角色分配+执行计划
3. 确认后，AI自动并行派发子Agent
4. 你等待结果，做最终决策

## 6大核心Agent

| 代号 | 角色 | 核心职责 | 常用工具 |
|------|------|---------|---------|
| 📋 PM | 项目管理员 | 拆解任务、协调流程 | cronjob, write_file |
| 🧠 策划师 | 创意策划 | 市场分析→创意方向 | web_search, web_extract |
| ✍️ 文案师 | 文案撰写 | 标题/卖点/详情文案 | write_file, read_file |
| 🖼️ 视觉分析员 | 视觉参考 | 风格/色彩/排版分析 | vision_analyze, read_file |
| 🔎 质检员 | 挑剔审查 | 找漏洞/挑毛病 | read_file |
| 🔗 整合师 | 终稿整合 | 综合产出为终稿 | write_file, read_file |

## 标准执行流程

### Phase 1: 需求策划（5-10分钟）
```
PM: 接收客户需求 → 拆解为子任务
策划师: 搜索竞品 → 分析趋势 → 输出3个创意方向
人类: 选择创意方向，确认brief
```

### Phase 2: 创意发散（10-15分钟）
```
文案师: 3个方向各写1套文案（卖点+标题+详情）
视觉分析员: 3个方向各出1份视觉参考分析
整合师: 3套方案并排呈现，供人类选择
人类: 选定方案
```

### Phase 3: 深度执行（30-60分钟）
```
策划师: 确定方案 → 输出设计spec（字体/色彩/构图参考）
文案师: 扩展完整文案 → 卖点提炼
视觉分析员: 生成详细提示词（用于Midjourney/SD）
```

### Phase 4: 质检优化（10-15分钟）
```
质检员: 5个角度审查（品牌一致性/转化逻辑/审美/错别字/技术合规）
→ 问题清单 → 文案师和策划师修改
→ 二次审查 → 直到0问题
```

### Phase 5: 延展交付（15-30分钟）
```
整合师: 主视觉延展到各平台尺寸
→ 输出：淘宝主图/拼多多主图/详情页/包装展开图/社交媒体版
→ PM: 生成交付文档+文件清单
```

## 真实案例：万凯PET瓶详情页

```
需求：设计万凯PET抗菌瓶淘宝详情页

Phase 1 → PM拆解：竞品分析+创意方向+文案+视觉参考+质检+延展
         → 策划师输出3方向：① 抗菌科技 ② 日本技术 ③ 环保可持续
         → 人类选①+②融合（抗菌科技+日本背书）

Phase 2 → 文案师：3套文案（抗菌卖点+日本技术背书+使用场景）
         → 视觉分析员：3份参考分析（科技蓝+简约白+自然绿）
         → 科技蓝最受欢迎

Phase 3 → 策划师：设计spec（科技蓝+极简构图+数据可视化）
         → 视觉分析员：MJ提示词（3版）→ 选中轴对称版

Phase 4 → 质检员：发现2个问题
         ① "抗菌率99%"缺少权威认证标注
         ② 文案有1个错别字
         → 文案师修改 → 质检通过

Phase 5 → 整合师延展：淘宝主图+详情页+拼多多主图+抖音封面
         → PM生成交付文档

总耗时：90分钟（传统方式约4-6小时）
```

## 与相关技能联动
- 配合 `flow-state-engineering` 在深度执行Phase做高质量产出
- 配合 `agentomics` 为每个Agent选择最优模型
- 配合 `budgeted-act-defer` 设定每个Phase的错误预算
- 配合 `sdof-framework` 将5个Phase固化为标准流程

## 注意事项
1. **人类永远做最终决策**：AI产出"候选"，你选"最佳"
2. **质检不可省略**：质检员的角色在整个流程中最重要
3. **Brief质量决定产出质量**：越详细的brief → 越精准的创意方向
4. **每次迭代记录版本**：保留每个阶段的产出，便于回溯
5. **Prompt工程是核心竞争力**：好的图像提示词决定80%的出图质量
6. **建立个人模板库**：成功的设计spec要保存为模板，下次复用
