### 🔧 技术实现

#### 数据存储
- **文件**: `~/.hermes/model_usage.json`
- **格式**: JSON
- **内容**: 模型使用统计、质量评分、时间戳

#### 配置文件
- **文件**: `~/.hermes/config.yaml`
- **配置项**:
  ```yaml
  smart_ranking:
    enabled: true
    top_n_models: 5
    weights:
      usage_frequency: 0.6
      response_quality: 0.4
  ```

#### 评分公式
```python
# 使用频率评分 (0-100)
usage_score = min(usage_count × 2, 100)

# 质量评分 (0-100)
quality_score = 综合评分

# 综合评分
score = (usage_score × usage_weight) + (quality_score × quality_weight)
```

### ⚙️ 配置选项

#### 基础配置
```yaml

  enabled: true        # 是否启用
  top_n_models: 5      # 优先展示数量
  weights:             # 评分权重
    usage_frequency: 0.6  # 使用频率权重
```
